ATRIUM REVAMP · INVESTOR JOURNEY · PRIYA RAMAN

UX audit and redesign: Home, Portfolio X-ray, Markets

Each page shows the current screen and what changes on the left, and the redesign on the right, built from Atrium Design System with the left icon rail. Figures that were cut off in the screenshots are filled with placeholders.

00

The shell, on every page

S1 Three navigation systems Stage tabs with checkbox icons, a 230px text sidebar for five items, and tabs inside pages all compete. The checkboxes read as filters. An 84px icon rail for pages. In-page tabs become a segmented control in the header. The stage moves into the person switcher, next to the role it belongs to.
S2 The guide takes a fifth of the width “Priya’s story” is a permanent 320px column, so tables and charts get squeezed on every page. The guide becomes one line in the top bar: progress, the current step and its action. The chevron opens all four steps as a menu.
S3 Amber means five things The logo, the active stage, Ask Atrium, “needs your attention” and the Growth band are all amber or orange. Amber is now only for caution. Ask Atrium uses the Gemini violet, so it matches the serif text the AI writes.
S4 Flat grey page, outlined cards Content sits straight on a grey-green page; where cards exist, thin borders separate them. White canvas with hairline-outlined cards. Shadows only for things that float.
